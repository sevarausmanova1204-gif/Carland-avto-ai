# Haqiqiy mashina rasmlari

Bu papkaga qo'yilgan rasm "🖼 Infografika" bo'limida avtomatik chiziladigan
sxematik diagramma o'rniga ko'rsatiladi.

**Fayl nomlash qoidasi:** fayl nomi (kengaytmasiz) mashina modeliga mos
kelishi kerak — katta-kichik harf, bo'sh joy va tinish belgilari muhim
emas. Masalan:

- `Cobalt.jpg` — bazadagi "Cobalt" modeliga mos keladi
- `cobalt-avtomat.png` — "Cobalt (Avtomat)" modeliga mos keladi

Qo'llab-quvvatlanadigan formatlar: `.jpg`, `.jpeg`, `.png`, `.webp`.

Rasm topilmagan mashinalar uchun avvalgidek avtomatik sxema ishlatiladi
(o'zgartirish shart emas).
